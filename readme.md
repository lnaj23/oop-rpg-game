## How to Run

### Required versions

- Java JDK: 25
- JavaFX SDK: 25.0.2
- Maven: 3.9.x or newer

### Installation

1. Install Java JDK 25  
   https://www.oracle.com/java/technologies/downloads/

2. Install JavaFX SDK 25.0.2  
   https://gluonhq.com/products/javafx/

3. Install Maven  
   https://maven.apache.org/download.cgi

### Compile the project

```bash
mvn compile
```
### Run the project

```bash
mvn exec:java
```
